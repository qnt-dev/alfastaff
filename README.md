# Альфа-Стафф · Recruiting — два варианта оформления

В одном репозитории доступны два оформления одного сайта:

- `index.html` — исходный оранжевый стиль и типографика, настоящий логотип компании в оранжевом оттенке;
- `brandbook.html` — стиль компании: красный `#C41718`, Montserrat, фирменные логотипы и приглушённая подсветка сфер.

Вверху страницы расположен временный переключатель **«Оранжевый / Брендбук»**. Активный вариант выделен; при переключении сохраняется текущий раздел. Обе страницы имеют прямые ссылки и работают на обычном статическом хостинге, в том числе из подпапки GitHub Pages. Каталог, интерактив, библиотеки и изображения у вариантов общие; отдельными оставлены только файлы, которые определяют оформление.

Чтобы убрать временный переключатель после выбора, удалить `nav.style-switch`, подключения `css/style-switch.css` / `js/style-switch.js` из обеих страниц и сами два файла.

Файл Benzin из брендбука не предоставлен: в красной версии заголовки временно используют Montserrat. Подлинный мини-брендбук компании представлен на `brand.html`.

Сайт объединяет два прошлых макета:

- **от QuantumFlux** (localhost:3333) — весь каркас и стиль: тёмная рама, белые листы со скруглением 30 px, «вырез» на первом экране, моно-метки `(АС® — 01)`, залипающие сплит-секции со счётчиком `1/4` в круговой надписи, строки `→ ИТОГ:` с печатью и курсором, бенто-карточки, бегущие строки, форма с вкладками; плашка меню и чат — по мотивам Xirex, Земля в подвале — по мотивам Agentory;
- **от Orange** (127.0.0.1:8081) — сфера объектов: те же шейдеры частиц, тёмное тело с белым ореолом и оранжевым низом, карточки складов, которые «садятся» на точки сферы.

Весь текст — про Альфа-Стафф: объекты в Москве и МО, Татарстане, Нижегородской и Самарской областях и во Владимире (каталог — из таблицы вакансий), условия вахты, профессии, услуги для бизнеса. Оформление — самозанятость.

## Запуск

Двойной щелчок по `run.bat` или:

```bash
python -m http.server 8090 --bind 127.0.0.1
```

Затем открыть http://localhost:8090/ (оранжевый вариант), http://localhost:8090/brandbook.html (фирменный вариант) и http://localhost:8090/brand.html (брендбук компании).
Сборка не нужна: чистые HTML, CSS и JS. Шрифты, three.js и Lenis лежат локально — сайт работает без интернета.

## Как обновить объекты

Объекты сайта собираются из таблицы «Вакансии ГК Альфа-Стафф.xlsx»:

```bash
python tools/build_objects.py "C:/Users/nksep/Downloads/Вакансии ГК Альфа-Стафф.xlsx"
```

Скрипт перезаписывает `js/objects.js` и пишет, что взял и что пропустил. Правила:
- на сайт попадают только доступные объекты — видимые колонки видимых листов; скрыли колонку в таблице — объект пропал с сайта;
- лист «Минск» (Беларусь), вакансии внутри компании (кухня, хостел) и объекты на паузе («стоп», «приостановлено» в названии) не берутся;
- не публикуются судимость, гражданство, требования к внешности, вычеты (спецодежда, медкнижка) и служебные пометки для кураторов;
- ставки, аванс, график, питание, жильё и дорога берутся из таблицы; аванс — как в таблице;
- координаты, короткие названия и район — в `tools/objects.config.json`. У нового объекта без записи там не будет точки на сфере и карте — скрипт об этом напишет;
- офисы — с листа «Адреса офисов» (координаты из ссылки на карту); Уфа как пункт отправки задана в настройках.

Общие цифры в текстах (ставки «от … до …», аванс, число объектов и регионов) сайт считает из каталога сам.

## Логотип

В обоих вариантах используется подлинный знак компании из PDF «альфа стафф_мини брендбук.pdf» и фирменная надпись в кривых. Геометрия знака не изменяется: красная версия хранится в `assets/brandbook/`, оранжевая цветовая адаптация — в `assets/brand-orange/`. Знак заменён также в фавиконке и анимации из частиц. Старый придуманный знак не подключается к страницам сайта.

## Что стоит подтвердить у клиента

- **Ставка.** На карточках сферы — «≈ 6 000 ₽» средняя за смену (решение по прошлому макету). В карточке объекта справа — точные условия из каталога (от 3 200 до 8 000 ₽ в зависимости от склада).
- **Тексты услуг для бизнеса** написаны по краткому описанию на alfa-staff.ru — формулировки «что входит» стоит сверить.
- **Цифры** 100% выплат без задержек, 90% возвращаются, «с 2015 года» — с alfa-staff.ru, не подтверждены. «С 2015 года» и «больше 10 лет» противоречат друг другу (на сайте оставлено «с 2015»).
- **Аванс** — как в таблице вакансий: 2 500–4 000 ₽, после 7 отработанных смен или каждую неделю (зависит от объекта).
- **Образцы документов**: акты — цифры из реальных актов (сентябрь 2026) по 11 объектам, ФИО шаблонное. Убраны залог, комиссия, ошибки, форма, проезд, медкнижка — «Всего к выплате» = начислено − авансы. У СДЭК и «Детского мира» актов нет; Владимир — без акта. Условия, кроме Тарного (с бумажного листа) и Владимира, собраны из каталога.
- **Чат** пока открывает Telegram с вписанным текстом — нужен сервис (Telegram-бот, Jivo или чат amoCRM).
- **Фото и имя рекрутера** для плашки чата — пока вместо фото знак компании.
- **Форма** пока никуда не отправляет — показывает «Заявка принята». Нужно решить, куда слать: amoCRM, почта или Telegram.
- **QR-код** ведёт на https://t.me/alfastaff, ВКонтакте — vk.com/alfa_staff_msk (оба — с их сайта).
- **Политика обработки персональных данных** — ссылка-заглушка.
